# Anvex v3.3.8 — Deep Audit / Remediation Report

## Scope

Full source-level audit of the v3.3.7 release candidate after the previous audit-correction pass; fixes are packaged as v3.3.8.
The audit covered build configuration, Room migrations, AI/chat execution routing, action parsing,
command translation, artifact packaging, project filesystems, import/export, provider credential
storage, preview server, LAN status server, plugin/skill boundaries, build-script trust boundary,
backup handling, Android component exposure, tests, documentation, and release hygiene.
