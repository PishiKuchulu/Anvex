# Anvex v2.9.1 — Deep Audit + Fix Report

## Scope
Full source-tree audit of the v2.9.0 package covering packaging, Room migrations, durable tasks, backup/recovery, approval boundaries, LAN status, filesystem/archive security, Android build boundary, PFP evidence and test governance.

## Fixed in this pass
1. Restored the packaged Android build source boundary: `ToolchainManager`, `AndroidBuildEngine`, `BuildScreen`.
2. Fixed durable retry recovery: `RETRYING` tasks whose `nextRunAt` is due are now selected and claimable.
3. Kept Android build tasks restart-safe and made temporary build state isolated outside the project root.
4. Added rollback-protected portable backup restore across provider state and settings; backup UI now calls the rollback-aware restore path.
5. Hardened backup envelope parameter validation for both portable and byte-oriented decrypt paths.
6. Hardened ZIP import/export entry-count and uncompressed-size limits for both files and directory entries.
7. Added retry/migration regression coverage.
8. Added a Room schema snapshot verifier; it fails rather than fabricating a schema/hash.
9. Hardened toolchain manifest path resolution so manifest-relative paths cannot escape the app-owned toolchain root.

## Verification
- PFP production-compliance static scan: PASS.
- Build source references: required build files present.
- Source ZIP contains no APK/AAB/keystore/build-cache artifacts.
- Gradle compile attempted but remains blocked by the environment because `services.gradle.org` cannot be resolved and the wrapper distribution is not locally cached.

## Residual blockers / honest limitations
- `BUILD_VERIFIED` is not claimed until a real Gradle environment compiles the project.
- `RUNTIME_VERIFIED` is not claimed until an APK is installed and exercised on a real Android device.
- Current package still contains only the foundation for Node/Linux/PTY/full Git/plugin execution; these are not falsely marked complete.
- Room schema snapshots for the current version must be generated by a successful Room/KSP build before production release.
- Installation Manager remains a diagnostic/task foundation; it does not download arbitrary JDK/Gradle/SDK binaries.
